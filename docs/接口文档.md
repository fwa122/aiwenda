## 一、通用约定

### 1.1 基础信息

| 项 | 值 |
| --- | --- |
| 基础路径 | `/api/v1` |
| 协议 | HTTP/1.1，SSE 用于流式问答 |
| 请求格式 | `application/json`（文件上传为 `multipart/form-data`） |
| 字符编码 | UTF-8 |
| 时间格式 | `YYYY-MM-DD HH:mm:ss`（服务端按本地时区存储） |

### 1.2 鉴权

除登录接口外，所有请求需携带请求头：

```http
Authorization: Bearer <token>
```

- `token` 登录后返回，前端存储于 `localStorage.kb_token`
- 返回 `401` 时前端清除 token 并跳转登录页

### 1.3 统一响应结构

```json
{
  "code": 0,
  "message": "ok",
  "data": {}
}
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `code` | int | `0` 表示成功，非 `0` 为业务错误码 |
| `message` | string | 提示信息，失败时为可读的错误原因 |
| `data` | any | 业务数据；分页接口为 `{ list, total, page, pageSize }` |

> 若后端不采用统一包装，前端 `request.js` 会自动透传原始 `data`（按是否存在 `code` 字段判断）。

### 1.4 分页约定

**请求参数**：`page`（默认 1）、`pageSize`（默认 10）

**响应结构**：

```json
{
  "code": 0,
  "data": {
    "list": [],
    "total": 100,
    "page": 1,
    "pageSize": 10
  }
}
```

### 1.5 错误码

| code | HTTP | 含义 | 前端处理 |
| --- | --- | --- | --- |
| 0 | 200 | 成功 | 正常渲染 |
| 40001 | 400 | 参数校验失败 | 提示 `message` |
| 40100 | 401 | 未登录 / Token 失效 | 清除 token，跳转登录页 |
| 40300 | 403 | 无权限 | 提示无权限 |
| 40400 | 404 | 资源不存在 | 提示资源不存在 |
| 40900 | 409 | 资源冲突（如重名） | 提示并保留表单 |
| 42900 | 429 | 触发限流 | 提示稍后重试，响应头 `Retry-After` |
| 50000 | 500 | 服务内部错误 | 提示系统异常 |

### 3.0 注册

```http
POST /api/v1/auth/register      # 公开接口，无需鉴权
```

**请求**

```json
{ "username": "zhangsan", "password": "Abc12345", "nickname": "张三", "email": "z@x.com" }
```

| 字段 | 规则 |
| --- | --- |
| `username` | 3~32 位、字母开头，仅字母/数字/下划线；唯一（重复返回 409） |

**安全约定**：服务端强制 `role=viewer`；受 `settings.security.enableRegister` 开关控制（关闭返回 403）；注册写入操作日志。

### 4.8 运行时模型信息（只读）

```http
GET /api/v1/chat/model
```

**响应**

```json
{ "code": 0, "data": { "model": "glm-4-flash", "embedding": "embedding-3", "available": true, "note": "当前模型由服务端（ai-service/.env）配置，暂不支持前端切换" } }
```

> 设置页展示用：返回 AI 服务当前生效的生成模型与 Embedding 模型及可用状态。
> **会话级模型选择**不走本接口：模型下拉选项由前端静态列表提供（当前 `glm-4-flash` 智谱 / `kimi-k2.6` Moonshot），选择结果存入会话（`model` 字段）并随 `/chat/completions` 传给 Python。
> 模型路由由 Python 按模型名前缀解析：`glm-*` → 智谱，`kimi-*`/`moonshot-*` → Moonshot；未识别的模型名回落全局默认（`LLM_MODEL`）。Embedding/Rerank/OCR 固定走智谱，与对话模型无关。
> 前端方法：`getRuntimeModel()`（只读展示）

### 4.9 上传附件（临时问答上下文）

```http
POST /api/v1/chat/attachments
Content-Type: application/json
```

**请求**：文件由前端 FileReader 转 base64 后随 JSON 提交（`data:` 前缀需去除）

```json
{ "files": [ { "name": "补充材料.pdf", "base64Content": "JVBERi0xLj…" } ] }
```

| 约束 | 值 |
| --- | --- |
| 格式白名单 | `pdf` / `docx` / `txt` / `md` / `csv`（与知识库上传一致） |
| 单文件大小 | ≤ 5MB（超限返回 413） |
| 每次数量 | ≤ 2 个（超限返回 400） |
| 文本截取 | 最长 6000 字（超出部分截断，`truncated=true`） |

**响应**

```json
{ "code": 0, "data": [ { "id": "att_xxx", "name": "补充材料.pdf", "chars": 4200, "truncated": false } ] }
```

**行为**：服务端同步调用 Python `/internal/extract` 提取文本并**暂存内存**（按用户隔离，过期自动清理）；随后在 `/chat/completions` 请求体传 `attachmentIds` 引用。附件内容仅作为**本次回答**的上下文，不写入知识库、不产生向量。
**引用规则**：附件不占用知识库来源编号，模型被要求直接提及附件文件名（避免悬空的 `[n]`）。
前端方法：`uploadAttachments(files)`

## 五、问答流式接口（SSE）

```http
POST /api/v1/chat/completions
Content-Type: application/json
Accept: text/event-stream
```

**请求**

```json
{
  "conversationId": "conv_001",
  "question": "支持哪些文档格式？",
  "kbIds": ["kb_001"],
  "model": "glm-4-flash",
  "stream": true,
  "retriever": { "topK": 8, "threshold": 0.25, "hybrid": true, "rerank": true },
  "attachmentIds": ["att_xxx"]
}
```

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `conversationId` | string | 否 | 为空时服务端自动创建新会话并在 `done` 事件返回会话信息 |
| `question` | string | 是 | 用户问题 |
| `kbIds` | string[] | 否 | 限定检索范围，为空表示全库检索；**服务端会按当前用户可见性过滤**（private 库不可见时被剔除） |
| `model` | string | 否 | 本次生成模型；按前缀路由（`glm-*`→智谱、`kimi-*`/`moonshot-*`→Moonshot），未识别回落默认 |
| `stream` | boolean | 是 | 固定 `true` |
| `retriever` | object | 否 | **会话级检索参数覆盖**：`{topK?, threshold?, hybrid?, rerank?}`，优先于知识库 `retrieverConfig`；`hybrid/rerank` 任一为 true 即启用「向量+词法 RRF 融合重排」 |
| `attachmentIds` | string[] | 否 | [4.9 上传附件](#49-上传附件临时问答上下文)返回的 ID；附件文本作为本次回答上下文（不入库、不占引用编号） |

### 5.1 事件流

> 协议约定：**只发 `data: {...}\n\n` 行**，事件类型在 JSON 的 `type` 字段中（不使用 `event:` 行）；每 15s 发送 `: ping` 注释行心跳（解析器天然忽略）。

```
data: {"type":"references","data":[ {Source}, ... ]}

data: {"type":"delta","data":{"content":"支持 "}}

data: {"type":"delta","data":{"content":"12 种"}}

data: {"type":"done","data":{"messageId":"msg_x","conversationId":"conv_001","meta":{"model":"glm-4-flash","elapsedMs":1420,"tokens":{"prompt":1820,"completion":640,"total":2460},"rewrittenQuery":null}}}
```

| 事件 | 时机 | `data` 结构 |
| --- | --- | --- |
| `references` | 检索完成、生成之前 | [Source](#26-source引用来源) 数组；为空表示未命中（有附件时不触发兜底） |
| `delta` | 生成过程中持续推送 | `{ "content": "增量文本" }` |
| `done` | 生成结束 | `{ messageId, conversationId, meta }`；`meta.rewrittenQuery` 为多轮查询改写后的检索查询（未改写为 `null`） |
| `error` | 异常中断 | `{ "message": "错误描述" }` |

> 客户端中断：直接关闭连接（前端使用 `AbortController`），服务端停止上游推理并落库 `status=stopped`（保留已收正文）。
> 防幻觉兜底：检索为空且无附件时，直接推送 `fallbackReply` 话术（`meta.model=fallback`），不调用 LLM。

### 5.2 前端对接

前端方法：`streamAnswer(payload, handlers)`，handlers 包含 `onStage` / `onChunk` / `onDone` / `onError`，返回 `{ abort() }`。真实后端下自动走 SSE；Mock 分支由 `mockStreamText` 模拟（`VITE_USE_MOCK=true` 时）。

## 十二、内部服务接口（Python AI 服务）

> Node BFF 与 Python 服务之间的调用契约。部署形态为内网调用（绑 127.0.0.1），**不对外暴露**。
> **鉴权**（v0.8.0 安全加固）：除 `/internal/health` 外均需 `Authorization: Bearer <INTERNAL_TOKEN>`；令牌为 32 字节 hex（`openssl rand -hex 32`），与 Node 侧 `AI_SERVICE_TOKEN` 保持一致。**fail-closed 设计**——Python 未配置 `INTERNAL_TOKEN` 时所有受保护接口一律返回 503（而非放行）。

### 12.1 接口清单（实际实现）

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| `GET` | `/internal/health` | 健康检查（豁免鉴权）：embedding/LLM 配置、数据库连接状态 |
| `POST` | `/internal/tasks/parse` | `{docId}` → Celery 入队，立即返回 `{ok, taskId, docId}` |
| `POST` | `/internal/extract` | 附件同步提取：`{name, base64Content}` → `{name, text, chars, truncated}`；白名单同上传，≤5MB，文本截取 6000 字，临时文件用后即删 |
| `POST` | `/internal/search` | 检索：`{kbIds[], query, topK, threshold, hybrid, rerank}` → `{results[], elapsedMs, total}` |
| `POST` | `/internal/chat` | SSE 问答：`references / delta / done / error`，协议同 5.1 |

> 早期方案中的 `/internal/parse`、`/internal/chunk`、`/internal/embed`、`DELETE /internal/index/{kbId}` 未实施：解析/切片/向量化由 Celery 任务一体化完成，向量数据随文档/知识库 FK 级联删除，无需独立接口。

### 12.3 问答请求示例（`/internal/chat`）

```json
{
  "question": "支持哪些文档格式？",
  "kbIds": ["kb_001"],
  "model": "kimi-k2.6",
  "history": [ { "role": "user", "content": "…" }, { "role": "assistant", "content": "…" } ],
  "topK": 5,
  "threshold": 0.28,
  "systemPrompt": "你是企业知识库助手……",
  "fallbackReply": "抱歉……",
  "temperature": 0.3,
  "topP": 0.85,
  "maxTokens": 2048,
  "forceCitation": true,
  "hybrid": true,
  "rerank": true,
  "attachments": [ { "name": "补充材料.pdf", "text": "附件提取文本…" } ]
}
```

| 字段 | 说明 |
| --- | --- |
| `history` | 最近多轮对话（由 Node 落库后组装传入）；非空时 Python 先做**多轮查询改写**（消解指代/补全省略，失败回退原问题） |
| `model` | 按前缀路由 Provider：`glm-*`→智谱、`kimi-*`/`moonshot-*`→Moonshot；未识别回落默认。Moonshot 侧强制 `temperature=0.6`（API 限制）并通过 `extra_body` 透传 `thinking`（默认 disabled） |
| `systemPrompt` / `fallbackReply` / 采样参数 | 由 Node 从系统设置读取传入，Python 无状态、不读 settings 表 |
| `forceCitation` | 强制引用：提示词硬约束 `[n]` 编号；回答中无编号时自动追加「参考来源」列表 |
| `attachments` | 附件文本（Node 已通过 `/internal/extract` 提取），前置进上下文但不占引用编号；有附件时检索为空不触发兜底 |

**SSE 生成流程**：查询改写 → 混合检索 → 相邻片段合并（同文档 chunkIndex 连续的去重叠合并）→ context 组装（`[n] 来源：文档 第x页` 编号格式，6000 字符预算截断）→ LLM 流式生成 → token 用量回传（API 返回 usage 为准，缺失按字符数估算）。

### 14.2 行为差异

| # | 场景 | 契约 | 当前实现 |
| --- | --- | --- | --- |
| 1 | 上传后解析 | 异步解析，前端轮询进度 | ✅ 已解决：Python Celery worker 自动消费，`pending→parsing→indexing→parsed`；确定性错误（非法路径/空切片）立即永久失败，瞬时错误指数退避重试 ≤3 次 |
| 2 | 权限 | `/users`、`/settings` 等需 admin | ✅ 已补 RolesGuard：`/users`(全部)、`PUT /settings`、`/api-keys`、`/logs` 限 admin，越权返回 403 |
| 3 | 错误码 | 细分 40001/40900/40400… | 当前直接使用 HTTP 状态码作为 code（400/401/403/404/409/413/500），细分错误码待统一 |
| 4 | 退出登录 | — | 无状态 JWT，logout 仅返回成功（如需强制失效需引入 Redis 黑名单） |
| 5 | SSE 生成内容 | LLM 真实生成 | ✅ 已接真实 LLM：会话级选择 GLM（智谱）/ Kimi K2.6（Moonshot），按模型名前缀路由；`AI_MOCK=true` 仍可切回模拟流做隔离调试 |
| 6 | 会话归属 | — | 所有会话/消息操作校验归属，越权返回 404（不泄露资源存在性） |
| 7 | 知识库可见性 | — | ✅ v0.8.0 新增：internal/public 所有登录用户可读，private 仅 owner/admin；写操作仅 owner/admin；问答 kbIds 服务端过滤 |

### 14.3 已验证的真实示例（供联调对照）

**登录**

**创建知识库**（注意：`threshold` 为浮点，`rerank/hybrid` 为布尔）

```bash
POST /api/v1/knowledge

```

**上传文档**（multipart，字段名 `files`，可多文件；白名单 pdf/docx/txt/md/csv，单文件 ≤20MB）

```bash
POST /api/v1/knowledge/{kbId}/documents   (form-data: files=@xxx.pdf)

→ data: [ { "id": "doc_xxx", "name": "xxx.pdf", "status": "pending", "progress": 0, … } ]
```

**统一响应与鉴权**

- 成功：`{ "code": 0, "message": "ok", "data": … }`
- 未带 token：HTTP 401 + `{ "code": 401, "message": "Unauthorized", "data": null }`
- 越权（非 admin 访问受限接口 / 非 owner 写 private 库）：HTTP 403 + `{ "code": 403, "message": "该操作需要管理员权限", "data": null }`
- 参数校验失败：HTTP 400 + `{ "code": 400, "message": "threshold must be an integer number", "data": null }`（class-validator 文案，后续统一为中文）
- 上传超限：HTTP 413（Multer `LIMIT_FILE_SIZE` 自动映射）
- BigInt 字段（如 `storageLimit`、`totalSize`、日志 `id`）已自动转为 Number，Date 为 ISO 字符串

**SSE 问答**（真实 LLM，`AI_MOCK=false`）

```
data: {"type":"references","data":[{"chunkId":"ck_xxx","chunkIndex":2,"kbId":"kb_xxx","kbName":"…","docId":"doc_xxx","docName":"…","docType":"pdf","page":6,"charCount":512,"score":0.9213,"content":"…"}]}

data: {"type":"delta","data":{"content":"根据当前"}}

…（逐段 delta）

data: {"type":"done","data":{"messageId":"msg_xxx","conversationId":"conv_xxx","meta":{"model":"glm-4-flash","elapsedMs":2853,"tokens":{"prompt":408,"completion":141,"total":549},"rewrittenQuery":null}}}
```

- 客户端 1s 中断后：消息 `status=stopped`，正文保留已收部分
- AI 服务不可达：`data: {"type":"error","data":{"message":"AI 服务连接失败（http://localhost:8000）"}}`，消息 `status=error`
- 检索为空且无附件：兜底话术走 `delta`，`done` 事件 `meta.model=fallback`，不消耗 token
